# `config/manager/` — the operator

The control-plane core. This directory creates the `agentprimitives-system`
namespace and everything the `spicebox-operator` Deployment needs to run: its
ServiceAccount, its RBAC, its durable memory volume, the Services other
components dial, and the admission webhooks that gate the CRDs.

## Files

| File                          | Purpose                                                                                                                                                                                                                                                     |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `namespace.yaml`              | The `agentprimitives-system` namespace.                                                                                                                                                                                                                     |
| `serviceaccount.yaml`         | The `spicebox-operator` ServiceAccount.                                                                                                                                                                                                                     |
| `role.yaml`                   | The operator's `spicebox-operator` ClusterRole. **Generated.**                                                                                                                                                                                              |
| `rolebinding.yaml`            | Binds `role.yaml` to the operator ServiceAccount.                                                                                                                                                                                                           |
| `role-debug.yaml`             | Namespaced Role + binding for the debug-token Secret (`create` is namespace-wide because RBAC cannot restrict `create` by `resourceNames`; `get` is narrowed to the one Secret).                                                                            |
| `runner-toolspec-reader.yaml` | The `spicebox-toolspec-reader` ClusterRole: read access to the cluster-scoped CRDs a runner looks up at startup (SpiceboxToolspec, ClusterSkill, SpiceboxToolkit). Bound per-session by the AgentSession controller, not to every SA.                       |
| `snapshotter-rbac.yaml`       | The `ap-snapshotter` ServiceAccount for workspace-snapshot Jobs. Intentionally carries no Role — the Jobs only `cp`/`rm` on mounted PVCs.                                                                                                                   |
| `deployment.yaml`             | The operator Deployment: runner/sandbox image flags, leader election, and the env wiring for SpiceDB, Postgres, NATS, Graphiti, embeddings, extractord, and the memory backend.                                                                             |
| `pvc.yaml`                    | `spicebox-operator-memory`, the durable volume for the sqlite memory store. Sized 10Gi to clear the 4Gi floor some cloud disk types enforce — do not lower below 4Gi.                                                                                       |
| `service.yaml`                | Two Services: `spicebox-gateway` (:8443) and `spicebox-operator` (:8082, the debug + per-session memory endpoints).                                                                                                                                         |
| `webhook.yaml`                | The `spicebox-webhook` Service (:443 → :9443) and the `spicebox-settings` ValidatingWebhookConfiguration. Settings/skill validators are `failurePolicy: Ignore`; the AgentSession-identity and ToolCall validators are `Fail` (fail-closed security gates). |

## Generated

`role.yaml` is **generated by `mage gen:api`** — controller-gen collects the
`+kubebuilder:rbac:` markers on `pkg/controllers/*/controller.go` and writes
this file. Do not hand-edit it; change the marker and regenerate, then run
`mage manifests`. Everything else here is hand-written.
