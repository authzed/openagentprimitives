# `config/crds/` — CustomResourceDefinitions

Every `agentprimitives.authzed.com/v1alpha1` CRD the platform serves:
AgentClass, AgentSession, Channel, MCPServer, Skill, ToolCall, UserIdentity, and
the rest. Installing these is what makes the API group exist; the operator's
controllers crash-loop on "failed to wait for caches to sync" if a CRD a
controller watches is missing.

## Generated

The `agentprimitives.authzed.com_*.yaml` files are **generated by
`mage gen:api`** (controller-gen, from `pkg/apis/v1alpha1/*_types.go`). Do not
hand-edit them — change the Go type and regenerate.

`kustomization.yaml` is the exception: it is **hand-maintained**. controller-gen
writes CRD files but never touches the resources list, so a newly generated CRD
is silently excluded from `install.yaml` until you add it here.
`TestKustomizationCoversEveryCRDFile` (in `pkg/platform/manifests`) fails when a
`*.yaml` file in this directory is missing from that list.

After `mage gen:api`, always run `mage manifests`.
