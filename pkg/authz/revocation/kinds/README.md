# `pkg/authz/revocation/kinds`

The registered `Invalidator`s. Each owns one revocable kind and the key format
that identifies an instance of it.

| Kind                          | Revoke key                                                   | Effect                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`credential`](credential/)   | `<secretNamespace>/<secretName>`                             | Notifies every registered holder of that credential so the next use re-reads it — failing closed if the Secret was deleted. Covers `UserIdentity` and `AgentIdentity` credentials alike. **It fans out to all targets, not just the broker cache**, because a credential can be frozen into a live object (`MCPTool` copies header/value into struct fields and never re-reads).                                                                                                                                         |
| [`toolorigin`](toolorigin/)   | `mcpserver/<name>`, `sidecartoolbox/<ref>`, `toolkit/<name>` | Adds the origin to a live set the runner's `PreToolCall` revocation guard consults; the next call to any tool with that `Origin()` is denied.                                                                                                                                                                                                                                                                                                                                                                            |
| [`sessionhold`](sessionhold/) | `<agentSessionNamespace>/<agentSessionName>`                 | Cancels the runner's root context, halting its turn loop, any in-flight tool call, and the lifecycle sequencer together. **Latency only** — the AgentSession reconciler's `SessionHold` park (`pkg/controllers/agentsession/hold.go`) parks and reaps the session's pods on its own next pass regardless. Each runner is constructed with its own session key and no-ops on any other key, because the bus has no per-session subject — every runner sharing a namespace sees every session-hold revoke published there. |

The revocation guard runs at order 12 in
[`../../hooks/order.go`](../../hooks/order.go) — after MCP trust, before the
toolguard breaker, so a revoked origin is denied before it consumes a rate slot
or a breaker probe.
