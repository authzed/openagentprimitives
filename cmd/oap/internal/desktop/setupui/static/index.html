Starting up

Set up OAP Desktop

Connect a model provider so your local cluster can run agents, and choose a password for the admin dashboard. You can change the model provider later; the password protects the admin dashboard's login.

OpenRouter models are namespaced, e.g. anthropic/claude-3.5-sonnet.
