# SkillSource

**Group** `agentprimitives.authzed.com` · **Scope** Namespaced · **Short names** `sksrc`

SkillSource is a git repo that yields one or more Skills.

Namespaced. Reconciled by pkg/controllers/skillsource, which clones at
spec.ref, discovers SKILL.md files under spec.subpath, caches each skill's
bundle by content digest, and materializes owned Skill CRs. Fetch and
discovery failures surface on the Ready condition and requeue on the sync
interval, so a bad credential or ref degrades this source rather than
crash-looping the operator.

## Spec

| Field | Type | Description |
| --- | --- | --- |
| `spec.auth` | `object` | Auth references the credential used to clone a private repo. |
| `spec.auth.agentIdentity` \* | `string` | AgentIdentity is the AgentIdentity CR (same namespace) holding the credential. |
| `spec.auth.credential` \* | `string` | Credential is the AgentCredential name on that identity (e.g. a github_pat). |
| `spec.disableRepoInstructions` | `boolean` | DisableRepoInstructions, when true, stops this source from discovering and attaching the repo-root agent-instructions file (AGENTS.md/CLAUDE.md) to the skills it materializes. Default (false) = enabled. |
| `spec.ref` | `string` | Ref is the branch, tag, or commit SHA to fetch. Empty = default branch (a rolling source — warned downstream). |
| `spec.repoURL` \* | `string` | RepoURL is the git repo to clone (e.g. "https://github.com/org/repo"). |
| `spec.subpath` | `string` | Subpath restricts SKILL.md discovery to this subtree. Empty = whole repo. |
| `spec.sync` | `object` | Sync controls re-polling cadence. |
| `spec.sync.interval` | `string` | Interval between re-polls. Zero → controller default (1h). |

<small>\* required</small>
