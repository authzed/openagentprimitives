# AccessToken

**Group** `agentprimitives.authzed.com` · **Scope** Namespaced · **Short names** `atok`

AccessToken is the AUTHENTICATION record for one inbound delegated
credential minted at OAuth consent: hash → token identity, plus display
metadata and expiry. It deliberately carries NO role and NO scope — the
authorization truth lives entirely in SpiceDB on accesstoken:&lt;name&gt;
(see pkg/authz/spicedb/schema/schema.zed). Deleting this object is
revocation: the finalizer removes the SpiceDB tuples.

## Spec

| Field | Type | Description |
| --- | --- | --- |
| `spec.clientID` | `string` | ClientID is the OAuth client the token was issued to. |
| `spec.clientName` | `string` | ClientName is the DCR-supplied display name, sanitized at mint. |
| `spec.expiresAt` \* | `string (date-time)` | ExpiresAt is when the token stops authenticating. The SpiceDB tuples carry the same instant via the expiration trait; this copy gates the authentication (hash-lookup) step without a SpiceDB round trip. |
| `spec.owner` \* | `string` | Owner is the canonical user id the token acts as. |
| `spec.tokenHash` \* | `string` | TokenHash is hex(sha256(bearer value)). The value itself is never stored server-side. |

<small>\* required</small>
