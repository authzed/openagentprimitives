# oap kg

Query the knowledge graph

## `oap kg communities <session>`

List detected knowledge graph communities

Flags:

```text
--json  Output as JSON
```

## `oap kg entity <session> <uuid>`

Get a knowledge graph entity by UUID

Flags:

```text
--json  Output as JSON
```

## `oap kg facts <session>`

Get all facts about an entity

Flags:

```text
--entity string  Entity UUID (required)
--json           Output as JSON
```

## `oap kg related <session>`

Find entities related to a given entity

Flags:

```text
--entity string  Entity UUID (required)
--json           Output as JSON
--limit int      Max results to return (default "20")
```

## `oap kg search <session>`

Search knowledge graph for facts

Flags:

```text
--json         Output as JSON
--limit int    Max results to return (default "20")
--text string  Natural language search query
```
