# Install on Desktop (macOS)

<div className="doc-lede">
  On an Apple-Silicon Mac, <code>oap desktop</code> is the fastest way to a working OAP. It boots a lightweight
  Linux VM, installs the entire stack into it with a persistent local memory backend, and gives you a menubar
  app to open a chat, open the admin dashboard, or install an agent — with no Kubernetes to set up and nothing
  reachable from outside your machine.
</div>

## First run, step by step

1. **Open the app.** Launch `oap.app`. The first time, right-click → **Open** (it's ad-hoc signed for local
   use). A menubar icon appears, animating a "setting up" state.
2. **Configure.** A native setup window opens with a short form:
   - **Model provider** — Anthropic, OpenAI, or OpenRouter.
   - **API key** — for that provider.
   - **Model** — optional; leave blank to use the provider's recommended default.
   - **Local admin password** — for signing in to the dashboard.
3. **Watch it come up.** On submit, the window switches to a live timeline: provisioning the disk image, booting
   the VM, installing components, and configuring the cluster (registering the model, provisioning sign-in, and
   applying a demo agent so there's something to talk to immediately).
4. **You're running.** The menubar icon flips to "running" and its menu enables.

## The menubar menu

Once it's up, the menubar icon is your control surface:

- **New chat…** — pick an agent and start a session in your browser.
- **Active sessions** — jump back into any live session.
- **Open dashboard** — the admin console.
- **Install agent from .oap…** — drop in a packaged agent bundle.
- **Stop** (keep your data) · **Uninstall** (remove the VM) · **Quit**.

All of those open a loopback-only browser tab into the local web server — nothing is exposed to the network,
and the tab is gated by the admin password you set at setup:

Picking **New chat…** opens the session picker in that tab — choose an agent and say what you need:

<Callout kind="tip" title="It's really local">
  The desktop stack runs entirely inside a VM on your machine, over a loopback connection. It's single-user by
  design and reachable only from your Mac — good for trying agents, developing, and demos.
</Callout>

Once it's running, head to **[Your first agent](/docs/quickstart)** — the demo agent is already there, and you can
add your own. The desktop stack does not include the [agent builder](/docs/agent-builder); one more command turns it
on — see [Turn on the agent builder](/docs/agent-builder-install).
