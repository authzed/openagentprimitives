# oap preferences

Inspect a session's resolved per-user preferences

## `oap preferences inspect <session>`

Show the resolved per-user preferences a session's agent sees

Flags:

```text
--json      Output as JSON
--turn int  User-turn index to resolve for (default: latest) (default "-1")
```
