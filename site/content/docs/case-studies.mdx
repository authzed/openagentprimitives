# Case studies

<div className="doc-lede">
  Hosted AI platforms keep shipping new features: a design canvas, a research agent, a coding assistant that
  opens pull requests. Each case study takes one of those features and shows how we built the same thing on OAP

  runs.
</div>

## How each case study is laid out

Every case study answers the same four questions, in the same order:

1. **What is it?** What the feature does, and what makes it useful.
2. **The ingredients.** What any team would need to build its own: a place to talk to it, a place for its
   output, access to the right data, and the guardrails around all three.
3. **How we built it in OAP.** The actual agent definition, start to finish, with the parts that matter shown
   in full.
4. **What's different on OAP.** Where the OAP version is more secure, more portable, or easier to adapt — and
   where the hosted original is still ahead.
