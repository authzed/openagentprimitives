# oap sandbox

Inspect SpiceboxSession resources (per-bundle running sandbox pods)

## `oap sandbox list`

List SpiceboxSession CRs in the namespace

## `oap sandbox show <name>`

Show a SpiceboxSession's spec, resolved class snapshot, pod, and conditions
